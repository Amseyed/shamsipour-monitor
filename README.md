# پایشگر اطلاعیه‌های شمسی‌پور برای Weblines

این سرویس RSS دانشگاه را هر ۱۰ دقیقه بررسی می‌کند و اطلاعیه‌های جدید را به گفت‌وگوی بله می‌فرستد.

## فایل‌ها
- `monitor.py`: برنامه پایش مداوم
- `Dockerfile`: دستور اجرای خودکار برنامه در زمان استقرار
- `requirements.txt`: وابستگی‌ها (فقط کتابخانه‌های استاندارد پایتون)

## متغیرهای محیطی در Weblines
- `BALE_TOKEN`: توکن بازوی بله؛ محرمانه نگه دارید.
- `BALE_CHAT_ID`: شناسه گفت‌وگوی مقصد در بله.
- `RSS_URL`: `https://shamsipour.tvu.ac.ir/?a=content.q.rss&lang=fa`
- `CHECK_INTERVAL_SECONDS`: اختیاری؛ پیش‌فرض `600` ثانیه.

در اولین اجرای موفق، برنامه یک پیام فعال‌شدن می‌فرستد و آخرین شناسه فید را ثبت می‌کند. اجرای مداوم وضعیت را در `/tmp/shamsipour_state.json` نگه می‌دارد؛ با بازسازی کامل کانتینر ممکن است این وضعیت پاک شود.

## نکته
این پروژه برای اجرای مداوم یک کانتینر طراحی شده است. در صورت مشاهده خطا، لاگ سرویس را بررسی کنید. هرگز توکن را در GitHub یا پیام عمومی قرار ندهید.
