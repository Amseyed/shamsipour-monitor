# پایشگر اطلاعیه‌های شمسی‌پور

این پروژه فید RSS سایت دانشگاه شمسی‌پور را بررسی می‌کند و اطلاعیه‌های تازه را به گفت‌وگوی خصوصی بازوی بله می‌فرستد.

## فایل‌ها
- `monitor.py`: دریافت RSS، تشخیص اطلاعیهٔ جدید و ارسال به بله
- `.github/workflows/monitor.yml`: اجرای خودکار هر ۱۰ دقیقه
- `state.json`: شناسهٔ آخرین اطلاعیهٔ پردازش‌شده

## راه‌اندازی
1. فایل‌ها را در شاخهٔ پیش‌فرض مخزن GitHub قرار دهید.
2. در GitHub به Settings → Secrets and variables → Actions بروید.
3. در بخش Repository secrets، `BALE_TOKEN` را با توکن بازوی بله اضافه کنید.
4. در بله، گفت‌وگوی بازو را باز کنید و `/start` بفرستید.
5. از Actions، گردش‌کار `Shamsipour RSS Monitor` را با `Run workflow` دستی اجرا کنید.
6. اگر شناسهٔ چت در گزارش اجرا نمایش داده شد، آن را به‌عنوان Repository secret با نام `BALE_CHAT_ID` اضافه کنید.
7. گردش‌کار را دوباره دستی اجرا کنید. پیام راه‌اندازی باید به گفت‌وگوی خصوصی برسد.
8. بعد از تأیید موفقیت، اجرای خودکار هر ۱۰ دقیقه انجام می‌شود.

- این برنامه در اولین اجرا فقط آخرین شناسهٔ فید را ثبت می‌کند و اطلاعیه‌های قدیمی را نمی‌فرستد.
- زمان‌بندی GitHub Actions ممکن است با تأخیر اجرا شود و تضمین لحظه‌ای نیست.
